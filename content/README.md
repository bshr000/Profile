# Content reference

Each file name becomes its URL slug. For example, `content/notes/my-note.mdx` becomes `/notes/my-note/`.

## Works frontmatter

```yaml
title:
description:
year:
category:
tags: []
cover:
github:
paper:
demo:
featured: false
```

## Notes frontmatter

```yaml
title:
date:
updated:
category:
tags: []
description:
draft: false
```

## Life frontmatter

```yaml
title:
date:
location:
description:
cover:
photos: []
tags: []
```
